CodeCrypt — Project Dossier

Theme: "Ghost in the Machine"

CodeCrypt is inspired by the Week 4 Hacktoberfest theme. Every codebase accumulates digital ghosts—forgotten scripts, obsolete protocols, and cryptic legacy logic written by engineers who have long moved on. CodeCrypt treats your terminal as an archaeological dig site, using open-weight local AI models to breathe new life into forgotten software.

Why Open Innovation Matters

  • Local Model Experimentation: Run high-performance open-weight models like Google's Gemma 2 entirely on consumer hardware without vendor lock-in.
  • Zero Data Exfiltration: Sensitive code, internal libraries, and proprietary logic never cross the wire to external cloud APIs.
  • Inspectable & Hackable: Clean, minimalist stack (Flask, Vanilla JS, CSS) with zero bloated frameworks, ready for developers to audit and extend.
  • Community Driven: Built for open-source exploration, hackathons, and reproducible AI development.

System Architecture

[Browser UI] ➔ [Flask API Server (app.py)] ➔ [Ollama HTTP API (/api/generate)] ➔ [Gemma 2 Model]

The backend serves strictly as an orchestrator and prompt boundary guard, enforcing strict input limits and prompt demarcations to prevent injection from untrusted source code.

Model Information

Default Model: {{ configured_model }} running through Ollama. Gemma 2 is an open-weight model created by Google. Note that open-weight model terms and Ollama's MIT license govern their respective components.

Security & AI Notice: All analysis is performed by your locally configured Ollama instance. AI outputs may contain inaccuracies or incomplete assessments; never execute unvetted code in production environments.
